# Interface rules for this project

- Every visible sentence must help a viewer act, read the chart, understand a change in the vote, or get essential context.
- Remove UI copy about prototypes, research packs, data methods, and our build process. Put that material in project documentation.
- Use plain language and specific names, votes, and episodes. Do not use slogans, sales language, mannered phrases, or routine disclaimers.
- Show a finding in the visual first. Use the update board for the one short sentence that helps the viewer read the selected vote.
- Do not repeat the same fact in the title, update board, legend, and chart. Each element must add something.
- Keep the chart and its controls high on the page. Check the layout in both modes before finishing.
- Before adding UI text, ask: “What will the viewer understand or do differently because of this line?” If the answer is nothing, delete it.
